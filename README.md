# Muhammad Abrar — Portfolio

Conversion-focused Next.js portfolio featuring AR-4U, ReplyMyMail, and Hayat Matrix Lab.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4
- GSAP + ScrollTrigger

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Content

Edit copy and case studies in `src/content/`:

- `site.ts` — positioning, contact, process
- `projects.ts` — flagship case studies
- `services.ts` — client offers

Set `NEXT_PUBLIC_SITE_URL` for production sitemap/OG URLs.
