WebAR only feels magical when the path from upload to shareable link is boringly reliable.

## Optimize for the first open

Most users hit AR from a QR code on mobile. Keep the marketing page light, preload what matters, and avoid shipping a full 3D editor to first-time viewers.

## Separate publish from create

Creators need a panel for models, accounts, and campaigns. Viewers need a focused viewer. Mixing those jobs usually hurts both UX and performance.

## Measure SEO and load together

For AR-as-a-service products, organic pages still matter. Treat SEO, image weight, and API payloads as the same performance budget.
